OOCADscript documentation

Introduction

    Object Oriented Computer Aided Design Script (OOCAD) is a domain specific language made for designing, simulating, and animating 3D models. It includes primative 3D shapes, extrusions and other 2D to 3D operations, CSG, fillet and chamfer tools, and thickened surfaces for generating 3D volumes.
    OOCAD is intended to be used with the CAD software, as it includes GUI elements to assist in generating and rendering the script. However, it is fully textual and human readable, so any text editor will work. Additionally, there is both a CLI and c++ API that can be used for rendering.

Syntax

    OOCAD uses the same comments as most popular languages: // for single line and /* */ for multiline.
    Each statement must end with a semicolon, unless it ends in a curly bracket.

Scopes

    A scope contains functions and variables. When a new scope is created, any previous scope's properties are still available, but not prioritized. For example, you can have two variables with the same name in different scopes, but the most recently declared one will be used.
    The global scope can be accessed using the variable "global", while the current scope can be accessed using "this". A scope has a reference to the previous scope, "this.parent" (null for global, since it is the last scope).
    When a function is called, all non-global scopes temporarily dissappear, leaving only the new function scope and the global scope. Once the function returns, the prevous scope is restored.
    A Scope is also a datatype. This means a scope, or a subset of a scope, can be passed around as an argument to a function, or returned from a function. If a function has a scope return type, then the function's scope is implicitly returned by default.
    When a scope is copied (i.e. returned), it loses its properties by default. The scope can be marked as keep by default, by prepending a $ in front of the type. Properties can be marked for keeping using a $, or for not keeping using ~$. A variable can be brought from the previous scope, by assigning $ to it. A scope can be leaked by prepending a $.

Built-in types

reference

A reference to another variable.

array

All of the following have an array variant, which allows multiple elements to be stored in a single variable.

float

A double precision floating point number, with around 16 decimal digits.

int

A 32 bit integer.

string

A list of characters.

vec2

A vector of 2 floats.

vec3

A vector of 3 floats.

Mat2

A 2x2 matrix of floats.

Mat3

A 3x3 matrix of floats.

Mat4

A 4x4 matrix of floats.

Point

A point in 3D space. Used as references in sketches and assemblies.

Axis

A reference line in 3D, which can be used to generate planes.

Line

A line in 3D space, which can be used as a path for sweep, or a reference in assemblies.

Plane

A reference plane, which can be used as a base for sketches. This is generally either axis aligned (XY, ZY, or XZ), or a flat face of a volume.

Interpolator

A function that interpolates between 2 or more points, with optional other parameters. This includes lerp (lines), bezier curves, hermite splines, arc segments, or any arbitrarily defined curve.

Edge

Uses an interpolator to generate an edge between two points, with optional other parameters.

Sketch

A collection of edges, used as a base for extrusions and similar operations.

Built in functions

vec2 project(point, plane);

Operators

Note that these are the primary use for these operators, but they can be used for other purposes.

Numerical

+, -, *, /, %, **
Standard numerical operators: add, subtrct, multiply, divide, modulo (remainder), exponentiate

Boolean

==, ~=, !=, <, >, <=, >=, &&, ||, !
Standard boolean operators: equals, fuzzy equals (almost equals), not equals, less than, greater than, less than or equal to, greater than or equal to, and, or, not

Bitwise

^, &, |, ~, <<, >>
Standard bitwise operators: xor, and, or, invert, bitshift left, bitshift right

Assignment

=, ?=, ++, --
Sets the value of a variable. Any of the previous operators, except boolean, can be used before an equal sign (=) on numerical types to reassign the new value.
Conditional assignment (?=) assigns only if the variable is null or undefined. Pre increment (++x) increments x, post increment (x++) increments x but returns the previous value, and decrement operators (--x and x--) work the same.

Dimensional

mm, cm, dm, m, dam, hm, km, in, ft, yd, deg, rad
Dimensional operators must immediately follow a number. It will be converted to meters or radians, but will be displayed in the file's units.

Other

., ?, <-, ->, [], (), @, $
Accessor operator (.) retreives a member of the variable (like a function or property). Conditional operator (?) assigns the right value if the left value is null or undefined. <- and -> may be used in the future. Array accessor ([]) is used to retreive an element of an array, starting from index 0. Call operator (()) is used to call a function, but may be used for a replacement constructor. Metadata operator (@) is used to define file properties, like default units and resolution. Import/Export operator ($) is used to import or export a variable, see scopes section for more details

Order of operations

From first to last evaluation: Anything in brackets goes first
